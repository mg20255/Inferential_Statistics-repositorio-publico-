En este código se explica paso a paso cómo pasar de usar las listas básicas de Python a trabajar con NumPy para manejar vectores y matrices. Primero se hace un repaso de lo más básico, como checar si un dato es entero, decimal o texto, y luego se muestra cómo funcionan las listas, midiendo su tamaño y entrando a cada posición recordando que en código siempre se empieza a contar desde el cero. Ahí es donde se nota el problema principal de las listas normales, porque si se intentan sumar dos de ellas con el signo de suma, la compu no hace ninguna cuenta con los números de adentro, sino que simplemente pega una lista al lado de la otra. Para solucionar esto, primero se enseña la forma tardada y a la antigua, que es hacer un ciclo con rangos para ir sumando posición por posición a mano o multiplicar por decimales como cero punto cinco. Después se entra a la parte buena con la librería NumPy, convirtiendo las listas en arreglos para poder hacer sumas vectoriales y multiplicaciones de un solo jalón y en una sola línea de código. Ya para terminar, se muestra cómo cambiar la forma de los datos agarrando un vector de veinte números que van del diez al veintinueve y acomodándolo en diferentes matrices, como de cinco filas por cuatro columnas o de diez por dos, para que quede bien claro por qué esta librería es la que se usa al momento de hacer cuentas y organizar datos.
